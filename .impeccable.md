# Design Context — Logos Patrum

## Target audience
Researchers, graduate students, seminaries, churches, and publishers studying
early Christian (patristic) texts — Arabic-first market, English secondary.

## Use cases
Read the Church Fathers in original languages (Greek, Armenian, Syriac),
compare translations, run morphological/philological analysis, trace citations
across manuscripts, protect licensed content.

## Brand personality / tone
Premium Academic SaaS. Calm, editorial, minimal, scholarly, precise, timeless.
References: Linear, Stripe, Notion, Apple, Vercel. Never playful, flashy, or
bouncy — motion communicates quality, not entertainment.

## Visual system
- White backgrounds; navy #21386E (primary-500) reserved for emphasis.
- One "live" signal: the orange #EE8D43 ping dot (from the hero eyebrow).
- Typography: Thmanyah Sans (Arabic, all roles), SF Pro Display stack (English),
  EB Garamond (Greek/Armenian passages). Swash alternates ("swsh") on headings.
- Kashida-stretched verb forms (نُــحــلل / نُتــرجمــ / نَــربــط) are brand
  gestures taken from the Figma comp — character-level, do not "normalize".
- Max width 1280px; 160px desktop section padding; GSAP for all motion;
  power3.out reveals; reduced-motion always honored.
